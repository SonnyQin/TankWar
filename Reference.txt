The game structure is inspired by Game Programming in C++: Creating 3D Games, 
including the use of Opengl,

The AI enemy is inspired by Programming Game AI by Example, including the use of 
statemachine, steeringBehaviors, A* Algorithm for path finding

Some help is provided by ChatGPT, such as the calculations of crossproucts, the use of glm for math calculations, and
some help for refining the render

The Maze Generator is built by https://blog.csdn.net/weixin_41604051/article/details/106363284


Models are all built by me, using blender, and exporters from Game Programming in C++: Creating 3D Games
